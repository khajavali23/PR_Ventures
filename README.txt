PR VENTURES HOMEPAGE
====================

Files:
- index.html       Main homepage
- style.css        Layout, typography, responsive styling
- script.js        FAQ accordion, mobile nav, back-to-top, demo form feedback
- assets/          Image crops taken from your supplied reference screenshot

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Safari, or Firefox.
3. Internet connection is needed for Bootstrap CDN and Google Fonts.

IMPORTANT
This is a close static recreation of the supplied screenshot. The supplied reference
image is 622 x 1600 pixels, so the photographic assets are cropped from that image.
Replace the placeholder phone number, email, project details, and social links with
the approved PR Ventures information. The enquiry form currently demonstrates
front-end validation and feedback only; connect it to a backend or form service
before production use.
